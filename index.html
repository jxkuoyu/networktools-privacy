概述

网络工具箱 / Network Toolbox（「我们的应用」）尊重您的隐私。本政策说明我们如何收集、使用和保护您的信息。

信息收集

设备上处理的信息

  • 网络信息：本地网络、Wi‑Fi、设备发现、端口等诊断数据，主要在本机处理。
  • 位置信息（使用期间）：系统可能要求位置权限以读取 Wi‑Fi SSID / 扫描周边网络。若您保存当前 WiFi，应用可能将反向地理编码后的地点文字与记录一并保存在本机。我们不会将精确 GPS 坐标上传到自有服务器。
  • 购买与使用状态：专业版档位、免费使用次数等保存在本机。
  • 设备监控列表：您收藏或监控的设备信息保存在本机。

第三方数据传输（仅在您主动使用对应功能时）

  1. 公网 IP：请求 ipwho.is，失败时依次改用 ipapi.co、api.ipify.org，获取公网 IP 及大致地理位置。
  2. 网速测试：连接测速镜像（中科大、清华、网易、华科、Cloudflare、Cachefly、OVH）以及 httpbin.org / speed.cloudflare.com，传输的是测速流量。
  3. Whois：向 Whois 服务器查询域名公开注册信息。
  4. 反向地理编码：保存 Wi‑Fi 地点时，可能通过系统服务把坐标转成地址文字。
  5. DNS 查询：诊断功能会向您指定的服务器，或在未指定时向公共解析器 8.8.8.8 / 1.1.1.1 发送 DNS 查询。
  6. 局域网发现：扫描时可能向 239.255.255.250:1900 发送 SSDP 发现请求，只用于发现同一局域网里的设备。

我们不收集

  • 不以广告为目的收集个人身份信息；没有广告追踪 SDK；不使用 IDFA 做跨 App 追踪。
  • 不收集通讯录、相册。

本地功能

请求调试：可以记录本应用发出的 HTTP/HTTPS 请求与响应（含正文；大流量测速只记元数据）。只存在本机，不上传。

设备监控与通知：专业版可以监控指定设备是否在线，并用本地通知提醒。系统后台任务可能周期性探测您配置的局域网 IP。

扫描历史：保存在本机。可以在设置里「清除本地数据」，也可以通过系统清除应用数据来删除。购买档位、语言和主题会保留。

本地存储

  • 购买档位：本机偏好设置。
  • 使用次数与 SSH 凭据：系统安全存储。已关闭 iCloud 同步，不会在您的设备之间共享。
